# Maho 1.0.0

Maho 1.0.0 release.

## Overview

Maho 1.0.0 marks the initial general availability release of Maho — built for people who take browsers seriously.

### What's New

- **Cross-Platform Releases**: Native installers available for macOS (Universal), Windows x64, and Linux (Debian, RPM, tarball).
- **Native MCP Server**: First-class Model Context Protocol integration supporting autonomous agent tools and leases.
- **AI Workspace**: Built-in conversational panel and workspace tools designed for modern developer workflows.
- **Privacy & Performance**: Native content blocking and optimized multi-tab resource management.
