# Maho 1.0.1

Update delivery infrastructure release.

## Overview

This release brings the browser's automatic update pipeline online and adds a
built-in changelog surface.

### What's New

- **Automatic updates enabled**: Maho now checks `update.mahobrowser.com` for signed updates on the stable channel. Updates are delivered as offline-verifiable signed envelopes; the rollout starts with a small canary percentage and widens gradually.
- **`chrome://maho-changelog`**: a bundled changelog WebUI. After an update is installed, Maho opens it once so you can see what changed.
- **Update feed hardening**: appcast responses are signed and length-pinned; mismatched signatures map to an explicit failure state instead of a silent install.
