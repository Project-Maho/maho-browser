# PROJECT KNOWLEDGE BASE — website

**Generated:** 2026-06-15

## OVERVIEW
Maho public website (`maho.app`): Astro 6 + Starlight docs + Starlight Blog + React landing/marketing pages. Serves browser/mail/CLI/API docs and blog posts alongside product pages.

## STRUCTURE
```
website/
├── src/
│   ├── content/docs/   # Starlight docs (browser/, mail/, cli/, api/, blog/)
│   ├── pages/          # Marketing pages: index.astro, mail.astro, privacy.astro, terms.astro, compare/
│   ├── components/     # Shared Astro + React components (Nav, Footer, LandingPage)
│   ├── layouts/        # BaseLayout.astro
│   └── styles/         # global.css
├── public/             # Static assets
├── astro.config.mjs    # Starlight + Blog + React integration
└── dist/               # Build output (gitignored)
```

## WHERE TO LOOK
| Task | Location | Notes |
|------|----------|-------|
| Browser docs | `src/content/docs/browser/` | Starlight MDX |
| Mail docs (GUI, MCP) | `src/content/docs/mail/` | Starlight MDX |
| CLI reference | `src/content/docs/cli/` | Starlight autogenerated sidebar |
| API reference | `src/content/docs/api/` | Starlight autogenerated sidebar |
| Blog posts | `src/content/docs/blog/` | starlight-blog plugin, prefix=`blog` |
| Landing page | `src/pages/index.astro`, `src/components/LandingPage` | React component via `@astrojs/react` |
| Compare pages | `src/pages/compare/` | Competitor/alternative pages |
| Site nav | `astro.config.mjs` sidebar array | Starlight sidebar config |
| Content schema | `src/content.config.ts` | docsSchema + blogSchema |

## CONVENTIONS
- Docs live under `src/content/docs/` — Starlight autogenerates sidebar for `browser/`, `cli/`, `api/`
- Blog posts use Starlight Blog plugin: prefix `blog`, RSS enabled
- React used for marketing pages only (`pages/`); Starlight handles all `/docs/*` routing
- `site: 'https://maho.app'` in `astro.config.mjs` — canonical origin

## COMMANDS

```bash
bun run dev     # Astro dev server (port 5555)
bun run build   # Build static site → dist/
bun run preview # Preview built site locally
```
