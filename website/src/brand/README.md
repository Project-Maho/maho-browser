## Literal-Color Exemptions

The following remain literal and are not recolored by the Maho theme system:

- Maho M mark gradients.
- macOS traffic lights.
- GitHub, YouTube, and Google marks.
- Favicons, including the retained Google and YouTube favicon rasters.
- External `/demo` rasters.

Maho-owned chrome and surfaces use theme tokens rather than literal colors.
