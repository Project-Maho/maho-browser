---
title: maho accounts
description: List all configured email accounts
---

List all email accounts configured in Maho Mail.

## Usage

```bash
maho accounts
```

## Arguments

None.

## Flags

None.

## Example

```bash
$ maho accounts
ID       EMAIL                  AUTH       NAME
acc1     alice@gmail.com        OAuth2     Personal
acc2     bob@fastmail.com       Password   Work
```
