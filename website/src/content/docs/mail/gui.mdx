## Overview

Maho Mail provides a fast, native desktop application built for reading, composing, and organizing email without relying on the terminal. It shares the same underlying local database and core engine as the CLI and MCP server interfaces.

## Features

- **Keyboard-first navigation**: Move through your inbox, compose messages, and manage folders entirely with keyboard shortcuts.
- **Dark mode**: Built-in support for system themes.
- **Smart inbox**: Automated sorting and AI-powered summarization (when configured).
- **Local-first privacy**: All your email is stored on your machine.

## Basic Usage

When you open Maho Mail, you will see your primary inbox. The interface is designed to be minimal and fast.

### Keyboard Shortcuts

- `c` - Compose new email
- `j` / `k` - Navigate up and down the thread list
- `Enter` - Open selected thread
- `e` - Archive thread
- `Command + f` - Focus search bar
- `Command + ,` - Open preferences

## Adding Accounts

Maho Mail supports standard IMAP and SMTP protocols. To add a new account:
1. Open Preferences (`Command + ,`).
2. Navigate to the **Accounts** tab.
3. Click **Add Account**.
4. Enter your credentials. Maho Mail will attempt to auto-discover your IMAP/SMTP settings.

## Offline Support

Because Maho Mail syncs messages to a local database (encrypted at rest via SQLCipher), you can search, read, and draft emails even when completely offline. Any drafted or sent emails will be queued and transmitted when you regain connectivity.
